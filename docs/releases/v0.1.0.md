## Download

- **GameShell.exe** — portable Windows x64 app; open it from a permanent folder.
- **GameShell-win-x64.zip** — the same EXE in a ZIP archive.
- **SHA256SUMS.txt** — SHA-256 hashes for both downloads.

.NET is included. The [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) is required separately.

## What's included

- User-defined profiles for monitors, TVs, projectors, gaming and other setups.
- Optional applications: Playnite Fullscreen, Steam Big Picture, Xbox App, or no application.
- Independent desktop actions and keyboard/controller shortcuts per profile.
- Default-setup configuration before optional profile creation on first launch.
- Faster transitions, accurate progress messages and short completion confirmations.
- Responsive layouts, clearer controls, and improved status/scrollbar spacing.
- Preserved profile settings during rename/save, with compatibility for older settings.
- Reorganized source and tests, a canonical profile editor model, and a code tour.

## First run and updates

Open the EXE, choose a language, save your default setup, and optionally create a profile. To update an existing copy, exit from the tray and replace the EXE in its existing location; your settings remain in `%LOCALAPPDATA%\GameShell`.

See the [user guide](https://github.com/MBllcode/GameShell/blob/v0.1.0/docs/user-guide.md) and [changelog](https://github.com/MBllcode/GameShell/blob/v0.1.0/docs/CHANGELOG.md) for details.
