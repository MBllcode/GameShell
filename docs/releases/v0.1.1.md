## Download

- **GameShell.exe** — portable Windows x64 app.
- **GameShell-win-x64.zip** — the same EXE in a ZIP archive.

## Changes

- Selected applications are brought to the foreground automatically; the redundant behaviour checkbox has been removed.
- Profile cards stay aligned on the left when the list needs a scrollbar.
- Updated screenshots and documentation; removed personal code-tour navigation.
- Simplified release assets to EXE and ZIP.

To update, exit GameShell from the tray and replace the EXE. Settings remain in `%LOCALAPPDATA%\GameShell`.
