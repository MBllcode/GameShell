## Download

- **GameShell.exe** — portable Windows x64 app.
- **GameShell-win-x64.zip** — the same EXE in a ZIP archive.

## Changes

- First-run setup discards the provisional profile when Back returns to its Displays step, clearing its application, desktop actions and shortcuts while keeping your default setup.
- **Create a profile later** becomes available again; repeated Back/Next navigation no longer accumulates unintended profiles.
- After skipping a profile, Back from General returns directly to optional profile creation.
- Dropdown options use an opaque dark background, independent of the closed control's hover state.
- Tray menu text uses a consistent, compact size, including **Open GameShell**.
- Updated first-run documentation and disposed unused tray menu resources.

To update, exit GameShell from the tray and replace the EXE. Settings remain in `%LOCALAPPDATA%\GameShell`.
