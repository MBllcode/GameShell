## Download

- **GameShell.exe** — self-contained Windows x64 app, now on .NET 10 LTS.
- **GameShell-win-x64.zip** — the EXE with LICENSE.txt and THIRD_PARTY_NOTICES.txt.

## Changes

- MIT project license and bundled third-party notices, available offline from General settings.
- Automated secret scanning, dependency auditing, license coverage tests and weekly dependency updates.
- Updated security policy and development documentation.
- Cleaned Git history: generated packages and the private walkthrough are removed; commit emails use the GitHub noreply identity.

Git history has been rewritten for privacy and size. Existing contributors should make a fresh clone instead of merging old history.

To update, exit GameShell from the tray and replace the EXE. Settings remain in `%LOCALAPPDATA%\GameShell`.
