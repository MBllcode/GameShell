## GameShell 0.2.1

This Windows x64 update improves profile shortcuts, display handling and the return to Default setup.

- Use saved controller combinations while GameShell is in the Windows tray. Each profile keeps its own combination.
- Recognize alternate identities for the same Samsung HDMI display and use its model name when available. Saved layouts and app assignments follow the reconciled display.
- Save display positions in whole pixels and reuse a preferred or remembered resolution when Windows reports no current mode.
- When **Close profile applications** is enabled, Default setup requests a normal window close for applications GameShell can verify it started during the session.

Download the portable **GameShell.exe** or **GameShell-win-x64.zip**. To update, exit GameShell from the Windows tray and replace the EXE in the same folder. Your existing profiles stay in `%LOCALAPPDATA%\GameShell`.
