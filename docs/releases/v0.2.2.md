## GameShell 0.2.2

- **Show window** lets the application choose its own window size and display. Apps with their own fullscreen mode, such as Playnite Fullscreen, can initialize it directly. **In background** minimizes the window without activating it.
- **Close profile applications** uses improved session tracking when returning to Default setup, with support for closing Playnite in desktop and fullscreen mode.
- The startup indicator follows the Default setup restore, and the dashboard shows warnings for profile actions that could not finish.

Download the portable **GameShell.exe** or **GameShell-win-x64.zip**. To update, exit GameShell from the Windows tray and replace the EXE in the same folder. Your existing profiles stay in `%LOCALAPPDATA%\GameShell`.
